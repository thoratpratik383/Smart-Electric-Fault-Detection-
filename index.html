About Project

What is the project?

Smart Electric Fault Detection System is an Arduino-based project designed to monitor electrical parameters such as voltage and current.

When an abnormal condition is detected, the system provides an alert using LEDs and a buzzer and can control the connected load through a relay.

Project Objectives

• Monitor voltage and current

• Detect abnormal electrical conditions

• Display system status on LCD

• Alert the user during faults

• Control the connected load using relay

How It Works

01

Sensing

Voltage and current sensors obtain electrical measurements from the circuit.

02

Processing

Arduino UNO receives and processes the sensor values.

03

Fault Detection

The system checks whether the measured values are within the defined limits.

04

Alert & Protection

LED, buzzer and relay provide fault indication and load control.

Circuit Connection Diagram

Arduino UNO receives sensor inputs and controls the LCD, LEDs, buzzer and relay according to the detected electrical condition.
